# Hero composite SVG asset plan

Status date: 2026-08-20

This plan creates a hero visual for the AgriFabric landing page and product/investor explainers.

## Asset set

| Asset | Purpose | Best use |
| --- | --- | --- |
| docs/assets/hero-composite.svg | Main landing-page hero visual combining Android field capture, backend evidence graph, admin operations, and bounded roadmap intelligence. | Landing page hero, product one-pager, investor intro. |
| docs/assets/hero-composite-compact.svg | Compact hero/banner version for slides, video title cards, and social previews. | Demo video opener, carousel cover, deck title slide. |

## Design direction

Use a layered product narrative:

1. Left: Android field capture.
2. Center: Backend evidence fabric.
3. Right: Admin/FPO operations and advisories.
4. Bottom/right: roadmap intelligence boundary.

The visual should feel like a platform, not a single app screen.

## Core message

> One field evidence fabric for capture, coordination, sync, advisories, governance, and future risk intelligence.

## Claim boundaries

- Field capture, offline sync, backend contracts, admin operations, advisories, localization, land-intelligence display, and audit are implemented foundation.
- Roadmap intelligence must be visually separated from implemented MVP.
- Do not imply live risk scoring, automated insurance decisions, or live provider execution.

## Visual acceptance checklist

- Clear hero-level composition, not too dense.
- Large enough to work as landing-page artwork.
- No overlapping labels or lines.
- Roadmap area uses dashed amber styling.
- Uses the same palette as existing SVG assets.
