# AgriFabric visual assets

This folder stores lightweight, repo-native visual assets used by documentation, future landing-page work, investor/product materials, and demo-video overlays.

Current assets:

- `relationship-graph-roadmap-layer.svg` — roadmap analytics layer visual showing how implemented evidence can feed future review-assistive modules.
- `relationship-graph-overview.svg` — simplified implemented traceability graph for landing-page hero/section use.
- `relationship-graph.svg` — static SVG for the AgriFabric relationship/evidence graph.

Source specs:

- `docs/relationship-graph-visual-spec.md`
- `docs/geography-digipin-visual-spec.md`
- `docs/demo-asset-inventory.md`

Guidelines:

- Keep visuals claim-safe.
- Mark roadmap/future modules with distinct badges or dashed outlines.
- Prefer editable SVG for diagrams and product visuals.
- Use raster screenshots/videos only for captured demo evidence.
