# Insurance and subsidy integrity roadmap SVG asset plan

Status date: 2026-08-20

This plan creates a claim-safe roadmap graphic for insurance, subsidy, credit, and risk-review use cases built on AgriFabric's implemented field evidence foundation.

## Asset set

| Asset | Purpose | Best use |
| --- | --- | --- |
| docs/assets/insurance-risk-roadmap.svg | Main visual explaining how implemented field evidence can support future fraud/waste/abuse review and claim evidence bundles. | Landing page roadmap section, investor/product one-pager, insurance conversation starter. |
| docs/assets/insurance-risk-roadmap-compact.svg | Compact version for demo overlays, thumbnails, and carousel slides. | Demo video overlay, social carousel, roadmap card. |

## Design direction

Use a two-zone layout.

Zone 1: Implemented evidence foundation.
- Farmer identity
- Parcel GPS/polygon/DigiPin
- Crop cycle and activity ledger
- Field event media
- Sync and audit trails
- Advisory read/ack lifecycle

Zone 2: Roadmap review intelligence.
- Duplicate parcel cultivation flag
- Claim evidence bundle
- Agent task-performance signal
- NDVI/time-series crop plausibility
- Weather/soil context
- Human review queue

## Core message

> AgriFabric does not need to decide claims to be useful. It can assemble trusted field evidence and flag inconsistencies for human review.

## Claim boundaries

- This is a roadmap graphic, not a live scoring engine.
- Do not claim automated claim approval/rejection.
- Do not claim operational fraud detection is implemented.
- NDVI/satellite time-series and live provider evidence remain future/approval-gated.
- The implemented foundation is field evidence capture, sync durability, backend validation, media, parcel precision, advisories, and audit.

## Visual acceptance checklist

- Roadmap/review nodes are dashed amber.
- Implemented evidence nodes use solid MVP colors.
- No label or line overlaps.
- The human-review boundary is explicit.
- The compact version remains readable in video/carousel context.
