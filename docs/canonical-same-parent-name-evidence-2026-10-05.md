# Same-parent village name and vernacular evidence

This read-only report evaluates the 3,939 canonical villages whose unmapped
NWDP source population already shares the normalized state, district and
block/tehsil parent.

Evidence signals remain separate:

- canonical, Census and Latin-script alias similarity;
- direct same-script vernacular similarity when both sides provide native text;
- vernacular availability, including an explicit false value when cross-script
  transliteration cannot be evaluated locally.

The report ranks at most three candidates per village and preserves ambiguity.
It classifies strong-single review, ambiguous/moderate review, weak signal and
no-name-signal queues. Thresholds are triage boundaries, never approvals.

No Indic transliteration package is installed. The report therefore does not
invent cross-script transliterations. A zero vernacular-evaluated count means
the required native-script evidence is absent, not that the villages differ.

The report performs no writes and does not authorize canonical, PIN, runtime,
project or Android changes.

## Validated result

The 3,939 villages partition into 130 strong-single review rows, 1,104
ambiguous/moderate rows, 1,007 weak signals and 1,698 rows with no useful name
signal. Strong similarity remains fallible: examples such as Samarpura versus
Amarpura demonstrate that scores cannot authorize a match.

Vernacular availability is zero on both canonical and NWDP sides for this
cohort, so zero vernacular comparisons were possible. Vernacular similarity
remains a required criterion when governed native-script aliases become
available; the current absence must not be interpreted as negative evidence.
